# ACSPL+ 常用调试命令速查

> 适用场景：ACS 控制器（ACSPL+）。示例中用 `AX` 表示轴号（0..7）。
> 注意：不同机型/项目可能存在安全互锁或自定义封装，执行前请确认现场安全条件。

---

## 单轴点动（JOG）

**命令**
- `JOG/v (AX), <vel>`

**用途**
- 以给定速度持续点动轴，用于手动找位或验证运动方向。

**注意事项**
- 需要轴已 `ENABLE` 且未被互锁。
- 通过 `KILL AX` 或 `HALT AX` 停止点动。
- 建议先用低速测试方向。

---

## PTP 位置运动（含速度参数）

**命令**
- `PTP (AX), <pos>`
- `PTP/v (AX), <pos>, <vel>`
- `PTP/rv (AX), <delta>, <vel>`（相对位移）

**用途**
- 绝对/相对点到点运动，带可选速度。

**注意事项**
- 确保目标位置在软限位与互锁允许范围内。
- 对于螺距/角度映射轴，注意单位（deg vs user units）。

---

## 回零（Homing）

**命令（示例）**
- `CALL HOME_TO_TORQ` / `CALL HOME_TO_SWITCH`（自定义回零子程序）
- `START <buffer>, 1`（启动回零 buffer，例如 #0..#7）

**用途**
- 执行回零流程并置位 `MFLAGS(AX).#HOME`。

**注意事项**
- 回零可能会改变 `FPOS/TPOS` 与 CPE 门限，确保完成后恢复。
- 若系统采用 buffer 回零，应从主控逻辑触发，避免与运动指令并行冲突。

---

## 读状态（运动/故障/回零）

**命令/变量**
- `MST(AX).#ENABLED`：驱动是否使能
- `MST(AX).4`：运动状态（0=运动中，1=停止/到位，具体依控制器定义）
- `MFLAGS(AX).#HOME`：回零标志
- `FAULT(AX)` / `MERR(AX)`：故障/错误码

**用途**
- 快速判断轴是否可动、是否到位、是否已回零，以及故障原因。

**注意事项**
- `MST(AX).4` 的语义需以现场配置为准。
- `FAULT(AX)` 通常为位域，必要时按位解析。

---

## 清故障/复位

**命令**
- `FCLEAR(AX)` 或 `FCLEAR ALL`
- `DISABLE(AX)` / `ENABLE(AX)`（必要时重新使能）

**用途**
- 清除故障标志并尝试恢复驱动状态。

**注意事项**
- 清故障不等于问题消失，需确认互锁与硬件状态。
- 某些故障需先 `DISABLE` 再 `ENABLE`。

---

## MFLAGS / MST 操作

**命令/示例**
- `MFLAGS(AX).#HOME = 1`（手动置位回零）
- `MFLAGS(AX).#DEFCON = 1`（默认连接/配置标志）
- `MST(AX).#ENABLED`（读使能状态）

**用途**
- 手动设置/读取轴标志与状态。

**注意事项**
- 手动置位 `#HOME` 可能绕过安全回零流程，需谨慎。
- `#DEFCON` 等标志的影响取决于控制器/项目配置。

---

## Buffer 控制

**命令**
- `START <buffer>, <priority>`
- `STOP <buffer>`

**用途**
- 启动/停止指定 buffer（例如回零 buffer 或通讯 buffer）。

**注意事项**
- 停止关键 buffer 可能导致互锁或通讯中断。
- 若 buffer 内有循环逻辑（如 `GOTO`），停止后需确认状态恢复。
